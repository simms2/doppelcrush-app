DoppelCrush Homepage Complete Asset Bundle

This bundle is organised so you can do the homepage update in one push.

1) reference/
   - target-homepage-design.png : the main design target to match as closely as possible.
   - asset-bundle-preview.jpg : quick preview sheet of the prepared assets.
   - early-clean-modern-direction.png : earlier cleaner direction for comparison.
   - previous-asset-preview.png : previous asset preview.

2) public/assets/
   Essential final homepage assets ready to place in your Next.js public/assets folder.

3) extras/stickers/
   Source sticker sheets / alternates if you want to swap or refine decorative elements.

4) extras/portraits/
   Source portraits / couple source images used to derive the homepage photos.

5) extras/source-previews/
   Earlier concept images and alternates, useful only as visual reference.
